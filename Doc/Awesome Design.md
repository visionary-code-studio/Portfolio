# Awesome Design
# Visual Direction for Vaibhav's Portfolio

## 1. Design Concept

### "A Digital Identity in Motion"

The portfolio should feel like a combination of:

```text
Editorial Design
+
Cinematic Motion
+
Personal Journal
+
Digital Archive
```

The visitor should feel that every scroll reveals another layer of Vaibhav.

The design should be:

**Minimal at first glance. Rich during interaction.**

---

# 2. Core Design Principle

Do not try to make every section visually spectacular.

Instead:

```text
Quiet
  ↓
Impact
  ↓
Quiet
  ↓
Interaction
  ↓
Impact
```

This creates rhythm.

If every section is animated aggressively, nothing feels special.

---

# 3. Visual Personality

The interface should communicate:

- intelligent
- youthful
- experimental
- creative
- technical
- confident
- curious
- ambitious

Avoid:

- generic SaaS aesthetics
- excessive glassmorphism
- dashboard-like layouts
- template-looking cards everywhere
- excessive gradients
- excessive neon
- "AI-generated portfolio" visual clichés

---

# 4. Design Language

The design language should combine:

### Editorial

Large type.
Generous whitespace.
Asymmetric composition.

### Cinematic

Full-screen visuals.
Slow movement.
Dramatic transitions.

### Technical

Grid structures.
Metadata.
Numbers.
Coordinates.
Small labels.

### Personal

Handwritten-style moments.
Short statements.
Unexpected copy.
Personal thoughts.

---

# 5. Color Direction

Recommended base:

```text
Primary Background
Deep Black / Near Black

Primary Text
Warm White

Secondary Text
Muted Gray

Accent
One signature color only
```

The accent should be chosen based on the hero video.

Example possibilities:

```text
Electric Blue
Acid Green
Warm Orange
Cobalt
Crimson
Violet
```

Do not use five accent colors.

The user should associate the one accent color with the portfolio.

---

# 6. Typography

Typography is one of the most important parts of this portfolio.

Use a combination of:

### Display Font

For:

- VAIBHAV
- section titles
- major statements
- large numbers

### Neutral Sans

For:

- body text
- metadata
- navigation
- descriptions

Recommended style:

```text
DISPLAY
very large
tight tracking
bold

BODY
clean
moderate line height
high readability
```

---

# 7. Hero Composition

The hero should be highly visual.

Concept:

```text
┌─────────────────────────────────────────────┐
│ VAIBHAV                         MENU        │
│                                             │
│                                             │
│          HERO VIDEO                         │
│                                             │
│      VAIBHAV                                │
│      [POSITIONING]                          │
│                                             │
│                                     01      │
│                                  SCROLL     │
└─────────────────────────────────────────────┘
```

The hero video should interact with the typography.

Examples:

### Technique A — Text Over Video

Large type overlays video.

### Technique B — Text Reveals Around Video

The video occupies the center while typography appears around it.

### Technique C — Typography Masks

The video becomes visible through oversized letters.

### Technique D — Video Expansion

The video begins contained and expands to full viewport as the visitor scrolls.

**Recommended:** Technique D.

It creates a strong transition from identity to story.

# 14. PPT Shelf Design

This should be one of the portfolio's most distinctive features.

Do not make it a conventional 3-column card grid.

Think:

### Digital Library

Large horizontal presentation cards.

Example:

```text
01

┌──────────────────────────────────────┐
│                                      │
│              COVER                   │
│                                      │
└──────────────────────────────────────┘

AI × EDUCATION

Research Presentation
2026
```

Cards can move horizontally while the page scrolls vertically.

---

# 15. PPT Shelf Interaction

Recommended behavior:

```text
Vertical Scroll
       ↓
Horizontal shelf movement
       ↓
Presentation card changes
       ↓
Metadata updates
```

This creates an immersive "archive" feeling.

---

# 16. PPT Hover

# 24. Texture

A subtle texture layer can make the interface feel less sterile.

Possibilities:

- film grain
- noise
- subtle paper texture
- faint grid
- scanline texture

Keep opacity very low.

The effect should be perceived rather than noticed.

---

# 25. Grid System

Use a consistent underlying layout.

Desktop:

```text
12-column grid
```

Mobile:

```text
4-column conceptual grid
```

Margins:

```text
Desktop: 5vw–7vw
Mobile: 5vw
```

Avoid placing everything in a centered narrow container.

This is an editorial portfolio, not a SaaS dashboard.

---

# 26. Motion Principles

### Rule 1
Every animation must communicate hierarchy.

### Rule 2
Large objects move slowly.

### Rule 3
Small UI elements can move quickly.

### Rule 4
Scroll movement should be noticeable but never nauseating.

### Rule 5
Animations should reinforce content.

---

# 27. Transition Style

Sections should not simply end and start.

Use transitions such as:

```text
Text → image
Image → text
dark → darker
small → enormous
horizontal → vertical
archive → manifesto
```

This makes the page feel continuous.

---

# 28. Sound

The reference site includes an explicit "Tap for sound" interaction.

For your portfolio, sound should **not autoplay**.

If sound is included:

```text
Sound OFF
       ↓
User activates
       ↓
Sound ON
```

A small audio toggle can be included if the provided video contains a meaningful audio layer.

Do not make sound mandatory for understanding the site.

---

# 29. Mobile Design

Mobile should not be a shrunken desktop design.

Recompose the layout.

Desktop:

```text
large horizontal compositions
```

Mobile:

```text
large vertical compositions
```

For example:

Desktop PPT:

```text
[01] [02] [03]
```

Mobile:

```text
01
────────
02
────────
03
```

---

# 30. Accessibility Mode

Respect:

```text
prefers-reduced-motion
```

When enabled:

- disable parallax
- disable large transitions
- simplify video behavior
- remove unnecessary cursor animation
- retain all content

The website must remain fully usable.

---

# 31. Signature Design Element

The portfolio should have one repeatable visual motif.

Recommended options:

### Option A
A small animated star / asterisk.

### Option B
A vertical chapter number.

### Option C
A moving line.

### Option D
A tiny coordinate/grid marker.

### Option E
A rotating personal monogram.

Choose **one**, then repeat it subtly throughout the site.

This becomes the site's visual signature.

---

The inspiration site emphasizes projects, experience, and publications.

Your portfolio should differentiate itself around:

```text
PERSON
   ↓
IDEAS
   ↓
PRESENTATIONS
   ↓
PROOF
   ↓
INTERESTS
   ↓
```

That creates a much more personal narrative.

---

# 33. Final Design Principle

> **Don't design every section to impress. Design the entire scroll to tell a story.**
